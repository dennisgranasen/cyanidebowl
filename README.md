# warp-scores

Welcome to [Warp-Scores](https://warp-scores.net), a Spike-like facade for Cyanide's BB3 API.

## Description
This is a [Spike](https://spike.ovh)-like web page to show match results and data from BB3 obtained through Cyanide's API. 

## Roadmap
- Match Details
- Authentication
- Admin results
- Win/Tie breaker editor
- Discord publishing of match results
- Coach page
- Statistics
- Support Knockout Tournaments an Brackets
- Support Swiss Tournaments
- NAF Data export for tournaments
- Generate Round Robin Schedules
